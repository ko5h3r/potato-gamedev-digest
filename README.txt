Potato GameDev Digest — site v3

Изменения:
- Убрана проблемная встроенная YouTube-плеерная секция.
- Добавлены 12 карточек выпусков по переданным YouTube URL.
- Превью берутся из официального thumbnail endpoint YouTube (i.ytimg.com).
- Каждая карточка открывает свой YouTube-выпуск.
- Добавлен горизонтальный слайдер: стрелки, drag мышью, swipe на телефоне.
- Добавлен усиленный mouse-parallax: 3 фоновых слоя + 3D-смещение hero.
- Сохранён мобильный адаптив.
- Сохранены блоки гостей, аудитории, платформ и рекламодателей.

Примечание: превью YouTube загружаются браузером с i.ytimg.com, поэтому при офлайн-просмотре они не будут видны.
