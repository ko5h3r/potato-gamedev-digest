Potato GameDev Digest — статическая вёрстка по референсу.

Запуск:
1. Откройте index.html в браузере.
2. Для локального сервера: python -m http.server 8000
3. Затем откройте http://localhost:8000

Файлы:
- index.html — структура
- styles.css — оформление и адаптив
- script.js — мобильное меню
- assets/ — предоставленные изображения
